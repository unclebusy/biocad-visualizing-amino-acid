# BIOCAD Visualization of amino acid sequence alignment

## Project Description

A tool for visualizing amino acid sequence alignments. Allows input of two sequences and visual comparison, highlighting matching and differing amino acids.

## Technologies

- TypeScript
- React
- Material-UI
- React Hook Form
- Jest for testing

## Features

- Input of two amino acid sequences
- Input validation (only valid amino acids and equal lengths)
- Alignment visualization with color coding
- Responsive design
- Copy selected sequences to clipboard
- Sequence search (Ctrl+F/Cmd+F)

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/biocad-visualizing-amino-acid.git
   cd biocad-visualizing-amino-acid
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Build the project:
   ```bash
   npm run build
   ```

## Testing

To run tests, use the command:
